# MC360 Dashboard v3

Live Demo: https://dashboardd-v3.netlify.app/

## Overview

MC360 Dashboard v3 is an enterprise dashboard concept for Maritime Connect 360. This version explores a structured dashboard layout with a focus on usability, navigation, and efficient access to maritime applications.

## Features

- Enterprise dashboard
- Dark interface
- Responsive layout
- Dashboard overview
- Applications screen
- User management
- Material Symbols icons

## Technologies

- HTML5
- CSS3
- JavaScript
